日子過得真快

发表于 2008-10-14 | 分类于 日常

很早在期待的花君SP也播過了，馬上就到GREASE公演的時候了。然後就是期末考試，再然後就是回家。

一年半都沒回家的我都沒有想家的感覺，冷血了這么多年了。聽娘說我從小就跟爹到處轉也沒哭過，見妹妹離開她娘一天就哭著要回家找娘親，那到底是一種什麽感覺？

每個星期會跟爹娘通話，其實每次不耐煩的都是我，我也不知道爲什麽會這樣，總之覺得他們有些啰嗦，我一個人會照顧自己的。

這么說太過分了吧？畢竟那是自己的爹娘，關心孩子是一定會的。雖然有的時候還是很期待星期六的到來。但爲什麽我從來沒有主動找過他們而只是等著，等到星期六他們就會跟我聯繫。不知道爹娘有沒有察覺。

或許是不想讓他們管太多關於自己的事情，但是另一方面，卻又花著爹娘辛苦賺來的錢。國內還好，國外那就是燒錢，我還遲遲不找工作。難道我出國本來就是一個錯誤？心裡面明明對爹娘有愧疚感，但還是這樣頹廢下去了。

嘆氣，暑假的三個月要在家裡過了，爹娘見到我一定會問我怎么胖成這樣，可以想象的家人的熱情，只不過我寧願他們低調一點。我不喜歡熱鬧，但又不想被人忽視。（←這個性格真是矛盾。）

本來這篇日誌沒想要寫這些，突然就很感慨，於是日誌被寫成這樣了，我真是，連自己都沒完全了解呢。（乾笑）

不說會後悔的廢話

发表于 2008-10-08 | 分类于 萌物

雖然說一周一集的動畫跟當初的《魔王》一樣等的心急，可還是忍不住要下載來看。又體會到當初每個星期等更新的心情。只不過當初追的是漫畫，現在是動畫而已。
鋼煉似乎是完結了，自從看過動畫結局之後就再也沒有看了。鋼煉的動畫結局多少還是有些怨念的，兩兄弟居然到了一個完全不屬於他們的世界，嘆氣。

似乎我跑題了？（天音：你有所謂的「題」可言么？）

其實剛開始并沒有打算要看《吸血鬼騎士》，因為是從同學那裡拷過來的也就一直沒有刪。《魔王》完結了之後好像突然缺了點什麽，所以拷了《蜂蜜與四葉草》的動畫來看。說真的，我對這樣的動畫不是怎么感興趣。我感興趣的比如《封神演義》啦，《死亡筆記》啦，《鋼煉》啦，《名偵探柯南》啦，說不上是什麽類型的。當同學對我說他有《吸血鬼騎士》的時候，我首先想到的是果子那個《罪與戰》的MV，於是就想看看原來的片頭做的是個什麽樣子。無意中我聽到了夜神月的聲音…
等等，夜神月的聲音？！突然就有興趣了，原因之二也是因為零sama的形象就是咱喜歡的type，本人是白髮控啊！不過說漫畫似乎還未完結，莫非又要痛苦的等待了么？

完美主義（？）的本人雖然有了全部還是去下了個打包全集（可憐的流量）。裡面帶了主題曲專輯，還有booklet的掃圖，被其中的一張小小打擊了一下。

零和枢兩個人看著很養眼，但是右下角那兩個人 好吧是我太過挑剔了

然後想說的就是《魔王》的赤阪宣傳。其實當時聽別人說在最後節目剩下一秒的時候斗真只說了「也～」，自己看的時候也確實看到了，從來沒有想到會用「喜感」來形容，但是今天看過0810期《生田斗真生存銘言》卻笑抽了。那個真的不怪你啊斗真，單說最後0.6秒的反映，你已經算是很厲害了，還知道要說「也～」的（使勁拍打）。

不知寫什麽作題目好orz

发表于 2008-10-04 | 分类于 日常

一直都想寫點什麽，拖到了現在，還是忍不住了。

最近都在說，離開了離開了。
姍姍辭了吧里的吧主，小舞也跟著要辭職。
於是大家感嘆爲什麼都走了。

見證過太多離別的我，似乎對這些已經麻木了。
又或許是早已知道所以到真正到來的時候就不會有任何反應？
暫別并不代表離開。

記得當初自己在群裡說要退群的時候，大家還對我說：這裡需要你。
反倒現在，我依舊在群里，大家都退了。
當初說的話現在看來一文不值。
其實真正該離開那裡的是我才對吧。
早就該離開了。

當初加了多少個群，去過多少個論壇。
不知道什麽時候就開始屏蔽掉群，發展到連論壇都不怎么去的狀況。
從來沒有說過離開，實際上卻真的離開了。
也沒有什麽人的挽留。
不過就是匆匆過客，什麽都沒留下。

是不是真的時間久了就會被大家遺忘掉。
又或許在未來的某一天，龍也群里的人也會忘記我的存在。
大家需要的并不是我，只是作為存在的一個話題。

最後留給自己的是最珍貴的記憶。
僅此而已。
